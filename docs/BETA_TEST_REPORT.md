## 테스트 방식 제한
로컬 웹사이트를 Chromium으로 직접 탐색할 때 `net::ERR_BLOCKED_BY_ADMINISTRATOR`가 발생했다. 그래서 UI 테스트는 동일한 HTML·CSS·JS를 Chromium DOM에 주입하고, HTTP 요청을 실가동 중인 Python API로 전달하는 베타 테스트로 교체했다. 이 방식은 클라이언트 상태/버튼/레이아웃과 실제 API 결과를 검증하지만, HTTPS·라우팅·CORS/프록시/CDN·운영 Cookie 정책을 검증하지 않는다.

## 발견하고 수정한 문제
1. 기존 v5 `service-worker.js`의 닫히지 않은 괄호로 인한 JavaScript 구문 오류 수정.
2. 관리자/결제/계정/API URL이 서비스워커의 공개 정적 캐시 대상에서 제외되도록 변경.
3. 기존 정적 상품 정보와 관리자 관리 데이터의 불일치를 줄이기 위해 베타 공개 상품 가격/재고/상태를 조회하는 브리지 추가.
4. 사용자 신원이 확인되지 않은 게시물/레시피가 공개되던 위험을 승인 기준으로 차단.
5. 단순 수량 수정 대신 재고 이력/사유/주문ID와 함께 원자적 입출고 처리.
6. 모든 통계는 테스트 DB의 실제 주문·이벤트에서 집계하고 가상 매출 수치를 표기하지 않음.
7. 관리자에서 직접 상품 등록/레시피 생성 기능을 추가하고 공개 기본값을 '초안'으로 제한.
