# 가락한상 V9 단일 패키지 검수 및 잔여 리스크

## 통합 원칙

1. `storefront`와 `admin_core`는 **로컬 원팩**의 단일 소스입니다. 예전 ZIP을 추가로 풀어서 덮어쓰지 않습니다.
2. 기존 Next.js GitHub 원본은 동일한 시스템의 **운영 후보 구현체**이지 로컬 API 서버와 동일한 DB를 쓰지 않습니다. 별도 스테이징 통합을 수행해야 합니다.
3. 디자인은 2번 시장 스토리형으로 통일. 패키지에 선택 시안 이미지와 기존 V8 실제 시연 페이지를 포함합니다.
4. 로컬 테스트 상품/주문·정산은 시뮬레이션일 뿐 매출·실고객 데이터가 아닙니다.
5. 수산 > 축산 > 농산, 레시피 132개, 커뮤니티·상인·요리사·협회 게시판, Blogger·외부 마켓은 운영 시 전용 인증/승인 절차 필요.

## 로컬 운영 QA의 합격 기준

`python tools/onepack.py doctor`와 `python tools/onepack.py qa` 모두 종료 코드 0, `QA_V9_RESULTS/V9_RUN_SUMMARY.json`의 모든 항목 PASS. 인증과 상품 API를 실제 `127.0.0.1` 서버로 테스트합니다. 테스트는 임시 DB를 생성하므로 운영 데이터에 영향을 주지 않습니다.

## 운영 출시 차단 조건

현재 운영 배포는 **NO-GO**입니다. 실제 `skvive/garak` 전체 원본 Next.js 빌드/마이그레이션, PG 웹훅·취소/환불, 상인별 재고/실정산, 배송사 연결, 구글 OAuth/블로그 저작권·광고심의, 모바일 E2E, 제품·레시피 이미지 진위검증, 운영 보안 심사, 백업복구/개인정보 점검을 마치고 결정해야 합니다.
