# 가락한상 상인 마케팅 월 구독제 및 쿠폰 성과수수료 사업 명세서
작성 기준 2026-11-03 · 사업 설계안 · 자동결제와 실제 정산 기능은 미개시

## 1. 핵심 구조
가락한상 월 매출 = 매장 마케팅 월 구독료 + 확정된 쿠폰 사용 거래의 약정 성과수수료.

- 구독료는 매장관리, 광고대행, 상품 소개, 상세페이지 관리, 광고 콘텐츠와 성과 리포트 작업에 대한 비용이다.
- 성과수수료는 쿠폰을 발행했다는 사실만으로 부과하지 않는다. 결제완료·유효 사용 거래만 대상으로 하며 취소·환불은 제외한다.
- 8%는 특정 업체의 실제 고정 수수료가 아니라 외부 플랫폼과 비교하기 위한 가정이다.

### 6만 원 판매 계산 사례
| 구분 | 금액 |
| --- | ---: |
| 외부 수수료 8% 비교액 | 4,800원 |
| 가락한상 고객 쿠폰 할인액 | 3,000원 |
| 추가 결제·배송 비용이 0이라는 단순화된 가정하 잠재 차액 | 1,800원 |
| 잠재 차액 50%를 가락한상 성과수수료로 적용 | 900원 |
| 상인의 비교상 건당 절감액 | 900원 |
| 100%를 가락한상이 받는 경우 수수료 | 1,800원 |
| 100% 배분 때 상인의 비교상 절감액 | 0원 |

공식: 외부 비교수수료 = 판매가 × 비교수수료율.
양의 차액 = MAX(0, 외부 비교수수료 − 상인 부담 쿠폰 할인액 − 자체 결제/배송/운영비).
가락한상 성과수수료 = 양의 차액 × 상인 합의 분배율.
상인 건당 비교 절감 = 외부 비교수수료 − 쿠폰할인 − 자체 추가비용 − 성과수수료.
상인 월 순절감(비교 가정) = 상인 건당 비교 절감 × 실제 사용 주문건수 − 월 구독료.
가락한상 월 매출(비용·세금 차감 전) = 월 구독료 + 성과수수료 × 실제 사용 주문건수.

예컨대 프로 33만 원 구독 + 50:50 배분 + 쿠폰 100건이면 가락한상 월 매출은 42만 원, 상인의 비교상 월 순절감은 -24만 원이다. 이는 추가 광고 유입과 실제 매출 증가를 별도 검증해야 함을 의미한다.

## 3. 상품권·쿠폰 구분
- 판매 할인쿠폰은 상품 구매 시 할인 혜택을 제공하는 마케팅 수단이다.
- 선불충전권·유상 상품권은 선불전자지급수단 등 전자금융 규제 해당 여부를 검토한 뒤 발행 방식과 가맹정산 방식을 확정한다.
- 지역사랑상품권, 온누리상품권은 공식 발행기관·가맹 승인 없이는 자체적으로 공식 상품권이라고 명명하거나 발행하면 안 된다.
- 쿠폰 할인 재원부담, 판매수수료, 결제대행비, 배송비, 광고 대행비를 정산명세에서 구별한다.
- 쿠폰 사용이 취소되면 성과수수료는 환급/차감하고, 정산 이력의 멱등성을 보장한다.

## 4. 실운영 프로그램 후속 개발
1. merchant_marketing_contracts: 상인, 상품, 월 가격, 자동연장·철회동의, 가입·해지 시점, 제공업무범위
2. merchant_marketing_deliverables: 광고 소재·게시·캠페인 운영 실적, 승인 이력
3. coupon_campaigns: 할인액, 재원부담, 유효기간, 최대 사용량, 대상, 사용 조건
4. coupon_redemptions: 주문 ID+쿠폰 ID 유일키, 결제완료·취소·환불, 사용일시
5. merchant_settlement_ledger: 매출, 할인액, 결제/배송 비용, 가락한상 성과수수료, 취소 조정
6. merchant_billing: 실제 반복결제 동의, 결제서비스 연동, 세금계산서, 환불, 웹훅 서명과 멱등성
7. Merchant admin RBAC: 상인별 본인 데이터만 조회, 승인 관리자만 수수료·요금 정책 변경
