| 관리자 로그인·감사 | 레시피 이미지 관리 별도 | PBKDF2/CSRF/RBAC/감사 로그 | Neon Auth/SSO/MFA로 전환 | 로컬 통과 / 운영 미완료 |

V6가 실행 가능한 **로컬 관리자 프로그램**이라는 것은 확인했다. 기존 Next.js 운영 웹앱 안에 코드를 병합해 프로덕션 Neon과 단일 권한·주문 원장으로 연계했다는 뜻은 아니다. 둘을 혼동하지 않는다.
