# 가락한상 | 수산물 특화 3대 수익 파이프라인 아키텍처
기준: 2026-11-03 / 실행 단계: 사업검토·시연 화면 (실제 도매발주·결제·구독청구 미개시)

## 1. 외부 벤치마킹 및 근거 구분
공개적으로 확인된 더파이러츠(인어교주해적단) 사업영역: 수산시장 시세·제휴 매장 정보, 앱 내 시장 주문/결제, 온라인 B2C·D2C 수산물 거래, 수산물 도매 B2B 및 자체 물류 납품.
- https://nextround.kr/startup/detail/2591 : KDB NextRound 기업 프로필. 상기 사업영역이 명시됨.
- https://v.daum.net/v/20210503142106545 : 2021년 전자신문 보도, B2C 소매몰 확대 및 B2B 납품/수산물 소싱.
- https://www.thebell.co.kr/front/newsview.asp?code=0303&key=202305101420036400102920 : 2023년 창업자 인터뷰 기반 정보·B2C·B2B·B2B2C 발전 배경.

**미확인**: 경쟁사의 현재 매출·영업이익에서 B2B가 최대 캐시카우인지, 실제 제휴점 광고 상품 요금·수수료율, 개별 업체의 독점 물류·수익 배분 계약. 이러한 수치는 가락한상 사이트에 사실로 게시하지 않음. 타사의 상표·사진·메뉴·DB·소스코드를 그대로 복제하지 않음.

## 2. 3대 수익모델 (계약·정산 코드 분리 필요)

| 사업라인 | 고객 | 거래방식 | 수익인식 | 현 구현 상태 |
|---|---|---|---|---|
| B2C / O2O 주문·포장예약 | 일반 구매자 | 검증 점포 검색 → 상품 옵션·원산지 확인 → 예약/결제 → 픽업 | 확정 거래의 약정 중개수수료(환불 제외) | 메뉴/점포 정보·시연, 거래결제/정산 미연동 |
| B2B 수산물 도매·납품 | 사업자 식당·횟집·급식업체 | 산지 공급자 사업자 검증 → 공급가 견적 → 발주 → 콜드체인 → 검수 → 정산 | 매입재판매: 납품매출 − 매입원가 − 물류·포장 − 폐기·클레임 / 순수중개: 계약 중개수수료 | 사업설계·공급마진 계산기만 구현 |
| B2B 상인 광고·마케팅 | 시장 상인 | 월 5개 구독제 및 선택적 실사용 쿠폰 캠페인 | 월 광고대행 구독료 + 계약된 쿠폰 성과수수료 | 요금 안내·쿠폰 수익계산기, 자동청구/성과검증 미연동 |

**중복 과금 방지:** 같은 구매 건에서 B2C 중개수수료와 쿠폰 성과수수료를 두 번 청구하지 않도록 상인별 계약에 `commission_scheme` 단일 선택 또는 통합 상한을 둔다. 광고/노출비와 거래비용은 별도 고지하고, 유료 우대 노출은 광고로 표시.

## 3. B2B 도매의 품질·법적 관문
- 공급자 사업자·영업자 등록과 계약·판매권한 확인
- 식품 품목·어종·중량·등급·원산지, 생산·수입·도매 증빙, 허위 원산지 표시 차단
- 냉장·냉동·활어 별 온도기준, 물류책임, 수령 검수기록, 이탈/폐기·반품 책임
- 계약 기반 도매 단가는 사업자 인증 및 업체 단위 접근 제어가 있는 서버에서만 제공 (정적 HTML·공개 JSON·git에 저장 금지)
- 품목·활동에 따른 식품위생·수산물 유통·세금계산서·전자상거래·물류 관련 규정 별도 확인
- 위탁 중개와 직접 매입 재판매를 구분하여 재고·매출·부가가치세 계산 처리

## 4. 운영 모듈 로드맵
1. 공급자/사업자 인증 및 비공개 공급가/단가 권한정책(Neon Auth / RLS 등)
2. 제품 마스터: 어종·원산지·등급·규격·당일 시세 및 검증일자와 출처 이력
3. 사업자 견적(RFQ), 공급가능 수량, 최소주문량·마감시간·거래조건 승인
4. 예약 및 B2C 온라인 주문: PG 결제, 픽업/배송 선택, 주문상태, 환불/취소
5. B2B 발주: 상인 공급 계약, 냉장 운송, 인수·검수, 미착/불량 반품
6. 계약별 수수료/재고/세금/정산 이벤트 원장(중복청구·환불 멱등성)
7. 마케팅 구독: 5개 등급의 제공서비스와 실제 작업실적·광고 노출표시·월 자동결제
8. 관리 대시보드: B2C GMV·중개수수료, B2B 매출총이익·물류손실, 광고 MRR·쿠폰 실제 사용수·환불조정

## 5. 수익 계산 예시 (실제 거래 수치 아님)
B2B 도매: 가정 매입원가 40,000원, 식당 납품가격 48,000원, 물류·포장 5,000원, 예상 폐기·검수 손실 1,000원. 건당 기여이익 2,000원, 월 100건 시 200,000원. 인건비·고정비·세금·실제 계약가를 제외한 모델.
B2C: 판매가 × 계약 중개수수료율 (실제 결제·환불·PG 비용 포함 정산 후).
광고: 월 구독료 + 유효 쿠폰 사용거래의 약정 성과수수료 (쿠폰 발행만으로 수수료 발생 안 함).

## 6. 구현 파일
- `storefront/merchant-marketing.html`: 3대 사업모델 카드, 마케팅 구독·쿠폰 경제모델
- `storefront/hybrid-business.css`: 모바일과 데스크톱 공통 반응형 스타일
- `storefront/wholesale.html`: 신규 B2B 도매·식당 납품 기획
- `storefront/wholesale-quote.js`: 비저장·비결제형 마진 시뮬레이터
- `storefront/brand/app.js`: 상인센터에 B2B 도매·납품 안내 진입
- `tools/generate_public_sitemap.py` + `storefront/sitemap.xml`: 검색용 공개 URL

**주의:** 실제 도매 결제, B2B 주문·물류 예약, 관리자 공급가 DB, Stripe 등 결제/청구, 식품원산지 공인 데이터 연동은 구현하지 않았다. 검토용 계획과 실제 운영 가능 기능을 혼동하지 않도록 UI에 명시함.
