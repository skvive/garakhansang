요리사 Google Blogger 콘텐츠 연동

내 계정에 소유권이 있는 블로그를 권한 승인 후 선택하고 공개 레시피 글을 가락한상 요리사 프로필에 연결합니다.

① Google 로그인

OAuth 2.0으로 접속. 타인 비밀번호를 수집하지 않고 접근권한을 최소화합니다.

② Blogger 목록 조회

GET /blogger/v3/users/self/blogs · 본인 운영 블로그 선택.

③ 공개 글 가져오기

글 제목·발행일·태그·대표 이미지·외부 링크. 전문 복제·재배포 범위는 운영자 승인 기준.

④ 레시피 상품과 연결

식재료 태그 매칭 → 관리자 심사 → 셰프 프로필·상품 상세에 카드 노출.

정식 연동은 Google Cloud OAuth 클라이언트, 서버 비밀키, 암호화 토큰 저장, 이용약관·개인정보처리방침, 공개 동의, 데이터 삭제 기능이 필요합니다. 이 시연본의 링크는 인증 완료를 의미하지 않습니다.

내 콘텐츠가 보이는 방법

요리사 이름 / 게시글 제목 / 대표 사진 / 요약 / 원문 바로가기 / 상품 재료 태그 / 협찬 여부 / 게시일이 표기됩니다.
